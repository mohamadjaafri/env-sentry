# Security Policy

## Reporting a vulnerability

Please do not open a public issue containing credentials, tokens, private keys, or other sensitive data.

For a suspected vulnerability in env-sentry, contact the repository maintainer privately through the contact details on the GitHub profile. Include reproduction steps and the potential impact. Do not include live secrets in the report.

## Scope

The scanner is a best-effort local and CI check. It is not a secrets vault and does not guarantee detection of every credential format. Continue to use dedicated secret-scanning and secrets-management controls.
